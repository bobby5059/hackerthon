# 페르소나 (Personas) — 테이블오더 서비스

본 서비스는 두 개의 핵심 페르소나를 대상으로 한다.

---

## Persona 1: 고객 (Customer) — "지민"

| 항목 | 내용 |
|---|---|
| **역할** | 매장에 방문하여 테이블 태블릿으로 음식을 주문하는 손님 |
| **기술 숙련도** | 보통 — 스마트폰/터치 UI에 익숙하나 별도 학습은 원치 않음 |
| **사용 환경** | 테이블에 고정된 태블릿(브라우저 웹 UI), 매장 내 |
| **주요 목표** | 대기 없이 빠르게 메뉴를 보고 주문하고, 내 주문이 잘 접수됐는지 확인 |
| **동기(Motivation)** | 직원 호출 없이 즉시 주문, 직관적이고 실수 없는 주문 경험 |
| **불만/장애물(Pain Points)** | 로그인/가입 절차, 복잡한 화면, 주문 성공 여부 불확실, 이전 손님 주문이 섞여 보임 |
| **핵심 니즈** | 자동 로그인, 카드형 메뉴, 장바구니 수량 조절, 주문 번호 확인, 현재 세션 주문만 조회 |
| **행동 특성** | 한 손으로 터치, 빠른 탐색, 짧은 집중 시간 |

**대표 시나리오**: 자리에 앉아 태블릿을 켜면 이미 로그인되어 메뉴가 보인다. 원하는 메뉴를 담고 수량을 조절한 뒤 주문을 확정하고, 주문 번호를 확인한 후 자동으로 메뉴 화면으로 돌아간다. 필요 시 현재까지의 내 주문 내역과 상태를 본다.

---

## Persona 2: 관리자 (Admin) — "성호"

| 항목 | 내용 |
|---|---|
| **역할** | 매장을 운영하며 주문을 모니터링하고 테이블/세션을 관리하는 운영자 |
| **기술 숙련도** | 보통 — PC/태블릿 관리 도구를 다룰 수 있음 |
| **사용 환경** | 매장 내 관리자용 웹 화면(PC 또는 태블릿), 로그인 필요 |
| **주요 목표** | 들어오는 주문을 실시간에 가깝게 파악하고, 준비 상태를 관리하며, 테이블 회전(세션)을 처리 |
| **동기(Motivation)** | 인건비 절감, 주문 누락 방지, 효율적 매장 운영 |
| **불만/장애물(Pain Points)** | 주문 지연 인지, 잘못 들어온 주문 정정, 테이블 정리 후 이전 주문 잔존, 과거 내역 추적 어려움 |
| **핵심 니즈** | 16시간 세션 로그인, 테이블별 그리드 대시보드, 주문 상태 변경, 주문 삭제, 이용 완료 처리, 과거 내역 조회, 테이블 태블릿 초기 설정 |
| **행동 특성** | 여러 테이블을 동시에 모니터링, 빠른 상태 전환, 확인 팝업으로 실수 방지 선호 |

**대표 시나리오**: 근무 시작 시 로그인하면 테이블별 카드 그리드에 실시간(폴링) 주문이 표시된다. 신규 주문을 확인해 '준비중→완료'로 상태를 바꾸고, 잘못된 주문은 삭제한다. 손님이 떠나면 해당 테이블을 '이용 완료' 처리하여 주문을 과거 이력으로 옮기고 테이블을 초기화한다. 새 테이블 태블릿은 번호/비밀번호로 초기 설정한다.

## 페르소나 요약

| 페르소나 | 접근 화면 | 인증 방식 | 핵심 활동 |
|---|---|---|---|
| 고객 (지민) | 고객용 웹 UI (태블릿) | 태블릿 사전 설정 후 자동 로그인 | 메뉴 조회·장바구니·주문·내역 조회 |
| 관리자 (성호) | 관리자용 웹 화면 | 매장 로그인 (JWT, 16시간) | 주문 모니터링·상태 변경·테이블/세션 관리 |
